# FALCON // ATELIER — Fine Art & Documentary Photography Showcase

An interactive, ultra-premium photography showcase and portfolio website built for visual artists and fine art photographers.

![Falcon Atelier Showcase](https://images.unsplash.com/photo-1464822759023-fed622ff2c3b?q=80&w=1200&auto=format&fit=crop)

## ✨ Key Features

- **Interactive Gallery & Masonry Grid**: Filterable by categories (*Street, Nature, Portrait, Architecture, Astrophotography*), live title/location search, and 2-col / 3-col / 4-col / feed density toggles.
- **Deep EXIF Inspector Lightbox**: Includes camera body specs, lens focal length, aperture, shutter speed, ISO, and **interactive color palette extraction** with click-to-copy HEX codes.
- **Mountain Landscapes RAW vs Grade Showcase**: Interactive split slider comparing uncompressed RAW sensor captures with signature color-graded artwork.
- **Fine Art Print Shop & Room Visualizer**: Interactive room wall mockup preview with frame material options (*Gallery Walnut, Matte Black Metal, Frameless Acrylic, Archival Canvas*) and live pricing calculator.
- **Visual Stories Journal**: Editorial photo essay reader.
- **Favorites Moodboard**: Saved photos drawer with shareable collection link generation.
- **Multi-Aesthetic Theme Engine**: Switch between *Obsidian Luxury*, *Editorial Light*, *Cyber Neon*, and *Warm Sepia*.

## 🚀 Quick Start

No build steps or Node dependencies required. Simply open `index.html` in any modern web browser or serve via any static web server:

```bash
# Clone the repository
git clone https://github.com/your-username/falcon-photography-portfolio.git

# Navigate to project directory
cd falcon-photography-portfolio

# Open index.html in browser or launch with Live Server
```

## 🛠 Tech Stack

- **HTML5**: Semantic structure & modern accessibility
- **CSS3**: CSS Custom Properties design system, glassmorphism, dynamic responsive grids
- **JavaScript (ES6+)**: Modular components, Web Audio API synthesizer for shutter sound effects
- **FontAwesome 6 & Google Fonts**: Outfit, Playfair Display, and JetBrains Mono
